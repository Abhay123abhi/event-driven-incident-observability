Email notifications

Control investigation and recovery emails from this running instance.

Checking notification service…

One-time setup

Configure SMTP_HOST, SMTP_PORT, SMTP_USERNAME, SMTP_PASSWORD, NOTIFICATION_FROM and ALERT_EMAIL_TO in your local .env file. Credentials stay on the server.

docker compose --profile email up --build -d notification-service

The switch applies immediately to subsequent event processing. An in-flight email may still finish. Muted events are consumed, not saved for later delivery.

On restart, the switch returns to EMAIL_NOTIFICATIONS_ENABLED from .env. The switch does not edit that file. SMTP configuration is checked for completeness, not delivery.
