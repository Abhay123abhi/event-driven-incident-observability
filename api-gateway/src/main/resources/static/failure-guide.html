LOCAL FAILURE LAB

Make failures visible.

Run one test at a time. Watch the alert, inspect its evidence, then restore the service.

ScenarioTriggerTiming / recovery
Slow Inventory./scripts/failure-test.ps1 -Scenario latencyP95 >2s for 2m; script resets after 5m

Prepare Inventory first

Set SPRING_PROFILES_ACTIVE=observability,demo in .env. Recreate Inventory, wait for healthy, and seed the product using the guide below. A 404 from /demo/failures means the demo profile is missing.

docker compose up --build -d --force-recreate inventory-service

Allow time for the 5-minute metric window, 15-second evaluations, 30-second new-group wait and up to 5-minute group-update interval. These are not instant alerts. A successful smoke test does not prove every evidence source is healthy.
